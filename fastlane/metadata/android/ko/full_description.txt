<b>PlainApp</b>은 무료 오픈소스 Android 앱으로, 휴대폰을 셀프 호스팅 관리 허브로 바꿔줍니다. 같은 네트워크의 어떤 웹 브라우저에서나 접근할 수 있으며 — 계정도, 클라우드도, 구독도 필요 없습니다.

<b>왜 PlainApp인가요?</b>

대부분의 휴대폰 관리 도구는 데이터를 자체 서버로 우회시키거나, 기능을 구독으로 잠그거나, 광고를 표시합니다. PlainApp은 다릅니다:

<ul>
<li><b>100% 로컬</b> — 데이터는 절대 네트워크 밖으로 나가지 않습니다</li>
<li><b>종단간 암호화</b> — 모든 연결이 TLS + XChaCha20-Poly1305으로 보호됩니다</li>
<li><b>무료·무광고</b> — 구매도 추가 판매도 영원히 없습니다</li>
<li><b>완전 오픈소스</b> — 코드 감사, 직접 빌드, 기여까지 자유롭게</li>
</ul>

<b>기능</b>

<b>웹 기반 휴대폰 관리</b>
같은 Wi-Fi 네트워크에 연결된 어떤 기기에서든 브라우저를 열어 Android 휴대폰을 관리하세요 — 컴퓨터 쪽에는 앱 설치가 필요 없습니다.

<ul>
<li><b>파일</b> — 내장 저장소, SD 카드, USB 드라이브 탐색; 업로드, 다운로드, 이름 바꾸기, 삭제</li>
<li><b>미디어</b> — 사진, 동영상, 오디오 조회 및 관리, 브라우저에서 스트리밍</li>
<li><b>연락처</b> — 연락처 보기, 검색, 관리</li>
<li><b>문자·통화</b> — 메시지와 통화 기록 열람, 데스크톱에서 문자 보내기</li>
<li><b>앱</b> — 설치된 앱 목록 조회 및 APK 내보내기</li>
<li><b>알림</b> — 휴대폰 알림을 브라우저로 실시간 표시</li>
<li><b>화면 미러링</b> — 오디오와 원격 제어를 지원하며 휴대폰 화면을 브라우저로 실시간 전송</li>
<li><b>기기 정보</b> — 배터리, 저장소, 네트워크, 시스템 정보 확인</li>
</ul>

<b>내장 Android 도구</b>
PlainApp은 그 자체로도 강력한 독립 앱입니다:

<ul>
<li><b>Markdown 노트</b> — 깔끔한 편집기로 노트 작성 및 정리</li>
<li><b>RSS 리더</b> — 방해 없는 리더로 즐겨찾는 사이트 구독</li>
<li><b>동영상·오디오 플레이어</b> — 재생목록을 지원하는 풀 기능 미디어 플레이어</li>
<li><b>TV 캐스트</b> — DLNA/Chromecast 호환 TV로 미디어 전송</li>
<li><b>P2P 채팅·파일 공유</b> — 서버 없이 기기 간 직접 파일과 메시지 공유</li>
<li><b>뽀모도로 타이머</b> — 내장 작업 타이머로 집중력 유지</li>
<li><b>소음 측정기</b> — 주변 소음 수준을 실시간 측정</li>
</ul>
